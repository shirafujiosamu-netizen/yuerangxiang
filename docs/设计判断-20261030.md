# 《月壤厢》独立游戏设计 · 第一轮判断

> 写于 2026-10-30。素材：11 条 B 站参考（见 `视频拆解-20261030.md`）、月壤厢世界观、已跑通的 Godot 四房与殡仪馆闭环。

## 一、这游戏其实在卖什么

不是「经营殡仪馆」，是**替死人办最后一件事，同时替神收账**。

玩家的每一次操作，都在两个账本之间做交换：
- 阳间账：钱、口碑（街坊 / 同业 / 官方）、时辰
- 阴间账：上供（从死者身上刮下来的东西）

阳间的账看得见，阴间的账只在打烊时露一下。玩家第一次意识到「我上供越多，赌场就越想认识我」，这游戏的味道才出来。

所以核心动词只有一个：**取舍**。不是「操作五道工序」，是「这单我要脸还是要钱」。

## 二、从参考里真正能抄的三样

1. **脑叶公司**：用「危险等级」把恐惧量化。死者按死法分 安 / 稳 / 凶 / 厉 / 邪，玩家扫一眼就知道这单值不值得碰。它的情绪条（好/普通/坏）对应我们的怨气。
2. **星空**：界面的秩序感来自「编号 + 细线 + 等宽小字」。标题屏已经这么做了，游戏内也该这样：每张案卷有编号，每条账目有行号。
3. **巨构**：把一个世界装进一个容器里。月壤厢就是盒子，五颗星球是盒子里不同的抽屉，大厅是抽屉的把手。

不抄的：卡牌、抽卡、堆叠数值成长。

## 三、七日节拍怎么立住

一天 6 格时辰，一单吃 3-5 格，所以一天办一到两单。第七天打烊时出账本。

三处要卡住玩家：
- **上供不够**：赌场不来，暗线不推进。
- **口碑崩了**：官方上门，当天不能接单。
- **尸变**：怨气推满，赔钱赔名声，还要多花一格处理。

七天内必须凑够三次上供，才够格让未型注意到你。这就是 demo 的目标感。

## 四、下一版该做的顺序

1. 大学场景接进房间系统（现在只有大厅和赌场有活路）
2. 未型在赌场里真正出现一次，说三句话，给一个托的活
3. 七日结束时一张结账单，写明这周做了什么、欠了谁
4. 大厅里三个可见入口（赌场 / 大学 / 书店），不再靠数字键

先做到「一局十五分钟能收尾」，再谈五个势力。
