# 月壤厢 · 游玩流程（2026-11-05 定）

> 她口述的完整流程，按顺序记下。实现时对着这张表逐段做。

## 1. 开始界面
- 菜单：新游戏 / 读取存档 / 画廊 / 设置 / 退出游戏 / 开发者说明
- 背景：3D 天体模型 + 宇宙星河，随鼠标移动旋转视角
- 美术风格：构成主义（Konstruktivizm）或复古未来主义（Retro-futurism）排版

## 2. 创建新游戏（选星球）
- 天体和星河放大到画面中央
- 鼠标拖动时，被拖动的星球转到画面中央
- 显示该世界介绍：开场产业 + 主线类型（用标准游戏分类术语：收集线索类 / 发展类 / 社交攻略类）

## 3. 选定星球（过场 CG）
- 星球模型放大到全屏 → 变成城市白模
- 开局产业落在城市里（不必在市中心）
- 作用：交代玩家的身份背景（殡仪馆打工大学生 / 失业继承旧书店 等）

## 4. 进入开局产业场景
- 例：完人之门 → 开局殡仪馆 → 第一幕 = 殡仪馆大厅
- 表现未定：2D 横版 还是 2D 文字游戏（待她定）
- 教程内容：卖香烛、开地图选目的地（地图 = 前面的城市白模，点道路/建筑传送）、触发事件、主动和 OC 搭话、安排一天行程
- 第二天去大学报到、第三天开学上课；教程三天后放玩家自由

## 5. Demo 过半
- 玩家已从「香烛 → 前台接待 → 接手葬礼主持」，有积蓄、在学校发展了一段时间
- 遇到 Eidos（理型）→ 进赌场，开赌场小游戏
