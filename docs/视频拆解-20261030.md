## 一、Pico RamOS 参考（四条）

**BV1nGnz6cETN《Windows 11 你唯一需要的桌面定制》**
- 全靠 Windhawk 的模块堆出来：任务栏竖排、开始菜单样式、通知中心样式、**Translucent Windows**（全窗口毛玻璃）、任务栏音量控制、Mond 桌面时钟。
- Windhawk 的设置界面值得抄：左边列表，右边 Detail / Source code / Changelog / Advanced 四页签，参数是一行一个开关加说明，改完点 Save。
- 关键信息：这套东西 4 分钟装完，说明「毛玻璃 + 细边 + 壁纸」不靠自绘，靠系统材质。

**BV1JDzPBGEtW《Windows 11 获得完整的磨砂玻璃效果》**
- 任务的顺序：先装 Translucent Windows，再装 Notification Styler，最后调 Mica/亚克力。
- 截图里那张设置页的背景会跟着壁纸变，所以「卡片透出壁纸」是预期效果，不是瑕疵。

**BV1qubR6dEVH《FluentFlyout》**
- 任务栏媒体组件：频谱可视化（滑块调高度）、进度条、播放控制，全部浮在一条窄玻璃条上。
- 设置页分层：常规 / 外观 / 集成 / 关于 Premium，每层两三组，超参数才给滑块。
- 对我们的意义：设置面板别做成一长列，按「常规 / 外观 / 行为 / 关于」四组，同组内才排开关。

**fluentflyout.com、github.com/unchihugo/FluentFlyout、github.com/Liset999/ZenDesktop**
- 两个都是「Windows 上把桌面做成一整块玻璃」的现成实现，ZenDesktop 更接近我们要的：整屏玻璃 + 卡片堆叠。

## 二、UI / 开始界面参考（七条）

**BV1gBc1eBEHn《星空》的美术、视觉、色彩与 NASA 朋克**
- NASA 朋克的三件套：白色/米灰的表面、红色标识或警示、等宽的细字标签。
- 界面语言：黑底、极细白线框、四角对准框、左下角一个圆环 HUD、右下角一列小字读数。
- 贴纸化的标签（STA 2140 / LOX TANK / COPY ACCESS / DO NOT STEP）说明：技术感来自「编号 + 短句 + 细框」，不来自发光。

**BV1Tsps6kE6z《被 NASA 废掉的标志怎么成了游戏里的未来感》**
- NASA 那版「蠕虫」字：只用红或黑，只能印在白色或浅灰上，字母等宽、几何化。
- 结论：一个词，压在上面，配一行等宽小字，比任何装饰都像「机构」。

**BV1EdnE6gE4Y《把一张构成主义海报拆开》**
- 只有红、黄、黑，平面色块，一条大斜线，字大到出画。
- 一个大数字当图形用（56.6%）。要点是「留白 + 一两个巨大元素」，不是塞满。

**BV1Zapz6PEWf《巨构：云在盛夏里涨潮》**
- 巨构的核心：一个玻璃盒子装着海与天，浮在城市上空。青绿配珊瑚红。
- 正好对应「月壤厢」的意象：一个装世界的盒子。天空不是背景，是盒子里的东西。

**BV1nF411e7TV《苏联美学演义·先锋派》**、**BV1YN4y1n7NZ《巨物恐惧》**、**BV1R4m6YYEjn《星云延时》**
- 巨物要「远」和「静」，靠空气透视与尺标；星云延时靠长时间堆栈，颜色要压住不要艳。

## 三、落到我们身上的改法

**月壤厢标题屏**
1. 整屏加一圈 1px 细框（内缩 40），四角各一行等宽小字：左上 `SLT-000 月壤厢`、右上 `五世界 / 已开其一`、左下操作提示、右下 `点一颗星落下`。细框就是「厢」的边。
2. 星球标签加编号：`01 完人之门 / 殡仪馆`，编号用等宽。
3. 大标题下一行等宽副题：`MOONDUST CASE · 案卷与门`。
4. 不加发光、不加渐变光晕，靠留白与字号差。

**Pico RamOS**
1. 设置面板按四组重排（常规 / 外观 / 行为 / 关于），每组两三行，滑块只给真需要连续值的项。
2. 卡片玻璃往 Windhawk 那版靠：材质交给系统（acrylic），页面只负责 1px 描边 + 内高光，不要自己叠渐变。
