## 二、事件系统：客人闹事 / 客人陪玩

事件是赌场（及未来各宇宙容器）的叙事载体，对标犹格「奇怪的客人们带着神秘事件到访」。

### 2.1 触发机制
- **闹事**：每 N 局（建议 5-8 局）概率触发；高污染/高欠债状态加权
- **陪玩**：每 N 分钟 + 角色关系值门槛（某角色剧情线推进后解锁）
- 事件不打断牌局：以「赌场事件」弹窗呈现，玩完这局再处理（或强制插入，视事件类型）

### 2.2 事件结构（文本游戏的最小单元）
```
事件 = { id, 触发条件, 事件文本(对话树), 选项[], 后果[], 关联角色 }
选项后果类型：资源± / 关系± / 解锁剧情线 / 特殊牌局(陪玩) / debuff / 无(纯叙事)
```

### 2.3 闹事型事件池（首期 5 个，**全部普通 NPC**）
> 边界（用户 2026-10-22 明确）：OC 角色不拿来做闹事背景板——她们是剧情主角池，只出现在专属剧情线/陪玩钩子里。闹事事件用世界观里的普通人/通用 NPC。

| 事件 | 闹事者 | 情境 | 选项 |
|---|---|---|---|
| 输光的赌徒 | 普通 NPC | 输红眼的客人拍桌子赖账，其他客人围观 | 替他垫付（资源-，声望+）/ 赶出去（无）/ 让 Eidos 处置（lore） |
| 出千者 | 普通 NPC | 袖里藏牌的惯犯被当场按住 | 围观（lore+1）/ 替他说情（Eidos 关系+） |
| 醉汉砸场 | 普通 NPC | 喝醉的异乡人开始扔杯子 | 叫保安（情绪-10）/ 自己上去（小赌局定胜负）/ 放任（设施耐久-） |
| 催债人上门 | 普通 NPC | 「上个月的利息」——阴暗讨债客 | 还钱（资源-）/ 赖（debuff：讨债人常驻）/ 赌一把抵债（特殊局） |
| 午夜不对劲 | 无（氛围事件） | 连败后赌场灯光变暗，影子多出一个 | 离场（debuff 清）/ 硬撑（高危高奖，SAN-） |

### 2.4 陪玩型事件（角色线钩子）
- **Eidos 陪玩请求**：「陪我打一局。规则我定。」→ 特殊规则局（如她发牌、她看得到暗牌、或赌注翻倍）→ 输赢都推进 Eidos 线
- **Ótakmarkað 定点巡视**：技能树看板角色在赌场出现时的对话
- **未来宇宙角色**：黄昏之门的 Celestia 等，跨宇宙来赌（多宇宙联动的种子）

### 2.5 与既有系统的接线
- 连输 5 局「完成」debuff 已实现 → 事件文案层接 `eidosLine`
- 赌局记录（casinoLog）成为事件的「前置事实」：闹事事件的触发条件可以读它（如连败 3 次后必触发听牌事件）
- 事件选择写角色关系值（新增 `s.bonds` 字段），关系值决定陪玩事件解锁与结局分支
