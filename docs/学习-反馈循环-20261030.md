# 学习笔记：反馈循环（Game Maker's Toolkit 拆解版）
来源：B 站 BV1dJhN6XEc1《10分钟讲透游戏设计的核心——反馈循环》（UP：游戏设计哈基米，12:31，5265 播放）
方式：videoshot 接触表看 100 帧（无字幕）

## 一句话
玩家上一轮的成败，改变下一轮成败的概率。这种事一旦成立，游戏就有「坡」，有没有坡决定它耐不耐玩。

## 分两类
- 正反馈：赢了更容易赢。雪球。例子：CoD 连杀奖励、文明滚雪球、Hades 的 Heat 层数、Dead Cells 的 Boss Cell。
- 负反馈：领先被拉回。橡皮筋。例子：马力欧赛车的道具、大乱斗的伤害百分比、战神里越级怪的压制。

## 两种都会坏
- 纯正反馈：前期一点优势变成不可逆，中期就没人陪玩了。
- 纯负反馈：努力没回报，玩家会觉得被系统按住。
- 常见解：让负反馈「只在差距过大时」启动，并且是可解释的（不是暗改概率，而是明着给你加难度、给对手补资源）。

## 对《月壤厢》的直接用处
1. **五门不能一家独大**。完人之门强了，其余四门要吃到「负反馈补偿」——比如官方查得松、同业愿意借人、巷里传你的名声。这样中后期还能有对手，而不是我自己跟自己玩。
2. **七日是一个循环单元**，每轮必须既有正反馈（钱、口碑、上供够数）又有负反馈（官方盯梢、同业挤兑、怨气累积）。目前只有加号没有减号，玩家会觉得「一直在爬坡」，没有紧张感。
3. **结账界面承担反馈的「解释」职责**。结算时把「这周你赢了什么、欠了什么、谁在盯着你」写成账目，而不是甩一堆数字。数字是证据，不是内容。
4. **赌桌就是正反馈的阀门**。放水当托抽六成＝用负反馈限制赌桌收益，防止玩家靠一张桌子通关。这条已经写进 `game.gd`，要保留。

## 待办（进代码前先想清楚）
- 给口碑三群加「衰减」：一段时间不维护，同业评价自然下滑。
- 官方那条线要有可见的进度感（从「没人管」到「有人来问」到「上门」），而不是随机事件。
- 五门之间要有一次「别人先动」的剧本，不能让玩家独自推进。
