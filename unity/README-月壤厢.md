# 月壤厢 · Unity 版（今晚这一版）

打开 `F:\job\oc-game\unity`，Unity 会自动进 Play（`Assets/.autoplay` 存在时）。
没自动进就点一次 ▶。

## 现在能玩到什么

1. 主菜单：星空 + 五颗带星系群的星球，鼠标拖动转视角，点「新游戏」进选星球。
2. 选星球：点任意一颗（现在五个世界都落到同一个 2D 大厅，具体场景统一用那张殡仪馆大厅图）。
3. 大厅：左上四个标签换场景（殡仪馆 / 书店 / 赌场 / 大学），底部一排地名点开是说明。
4. 殡仪馆服务台：接单 → 收尸 / 洗身 / 穿衣 / 念辞 / 出殡，每道三选一，改怨气、花钱、花时辰。
5. 结账：`身家 ×(100 − 怨气)/100`，怨气 ≥ 85 夜里尸变，官方 −8、街坊 −5。
6. 打烊：日结（人情衰减、对手推进、官面热度、夜里事件），天数 +1，时辰回满 6。
7. 七日账：每天一行，附官面进度和四家对手的分。
8. 书店：买《丧仪备要》¥120（街坊 +3）、书架翻一页（时辰 1、同业 +1）、后间看骨灰盒。
9. 赌场：押大 / 押小 / 当托放水，三种结果文案都按 godot 版规则。
10. 大学：听课（同业 +3）、查旧档（¥60、官面 −2、官方 +2）、雇学生（¥150、时辰 +1）。
11. 存读档：服务台的「存档 / 读档」，文件在 `%USERPROFILE%\AppData\LocalLow\DefaultCompany\unity\yueliangxiang.save.json`；主菜单「读取存档」直接进。
12. 主菜单的「画廊 / 设置 / 开发者说明」三个面板（现在只有文字，没有配图）。

## 按键

- `1`–`4` 换场景　`C` 服务台　`R` 七日账　`T` 打烊　`Esc` 关面板
- 右键拖动转视角、滚轮远近（3D 场景用，现在 2D 不吃这套）
